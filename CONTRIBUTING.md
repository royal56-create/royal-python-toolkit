# Contributing

Thanks for your interest in Royal Python Toolkit!

1. Fork the repository and create a branch for your change.
2. Use Python 3.9 or newer.
3. Install development tools with: python -m pip install -e ".[dev]"
4. Add or update tests for changed behavior.
5. Run: python -m pytest
6. Open a pull request explaining the problem and solution.

Guidelines:
- Prefer the Python standard library for core functionality.
- Keep functions small and documented.
- Handle invalid input with clear errors.
- Never transmit user files, secrets, or text without explicit consent.
